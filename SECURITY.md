# Seguridad

Este proyecto está en desarrollo y no tiene una versión pública de producción aprobada. Responsable de triage y decisiones de publicación: Kalista (mantenedora del repositorio).

Para informar de una vulnerabilidad, usa [Report a vulnerability](https://github.com/tears-mysthrala/chat-overlay/security/advisories/new), el canal privado de GitHub habilitado en este repositorio. No abras un issue público con tokens, datos personales o detalles explotables. Incluye versión/commit, entorno, impacto y reproducción mínima sin datos reales.

No se promete todavía un plazo contractual de respuesta ni soporte de versiones antiguas. Antes de distribuir se fijarán periodo de soporte, actualizaciones y política aplicable. Las obligaciones regulatorias se evalúan separadamente; este documento no acredita conformidad.

Procedimiento: [operación](docs/operations.md). Hallazgos conocidos y alcance de los escáneres: [dependencias](docs/dependencies.md).
